## CampReady Privacy Policy
**Effective Date: June 2026**

CampReady is built as a privacy-first utility application. 

### 1. Data Collection & Transmission
- **No Personal Data Collection:** CampReady does not collect, track, or harvest any personally identifiable information, account credentials, or user locations.
- **Local On-Device Storage:** All user-created packing manifests, travel checklists, and gear data configurations are stored strictly on the user's local device. No data is synchronized or transmitted to external company databases or tracking servers.
- **Affiliate Link Tracking:** Clicking the price tag icons launches native search parameters to help users find camping gear. As an Amazon Associate, the developer earns from qualifying purchases.

### 2. Contact Support
For support queries, data deletion checks, or policy questions regarding CampReady, contact your developer support email.

## BuildPilot Privacy Policy
**Effective Date: June 2026**

BuildPilot is built as a privacy-first project tracking application.

### 1. Data Collection & Transmission
- **Local Project Data Storage:** All vehicle build notes, parts lists, and modifications are stored strictly on the user's local device configuration.
- **Analytics:** No behavioral user analytics or remote telemetry tracking maps are initialized within this app package.
